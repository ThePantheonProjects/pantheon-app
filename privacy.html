Privacy policy

Last updated: 27 October 2026

Pantheon is a private application used only by its owner, Lior Milgrom. It is not available to anyone else.

What data it accesses

With the owner's consent, Pantheon reads the owner's own Gmail messages (read-only scope) and calendar, in order to alert the owner about important messages and events.

How data is used and stored

Data is processed only on servers controlled by the owner, only to serve the owner. It is not sold, shared with third parties, or used for advertising. Pantheon's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
